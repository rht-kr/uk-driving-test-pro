# DriveReady UK Driving Theory Pro

A polished React + Vite learning application for UK car driving theory preparation.

## Included
- Login / signup / demo mode
- 500 practice questions across 25 topics
- Image/illustration on every question
- Explanation after every answer
- 25 theory chapters including vehicle mechanics and safety
- 50-question mock exam, 57-minute timer and 43/50 pass target
- Hazard perception practice with 14 scenarios
- Progress dashboard, streaks and local persistence
- Responsive desktop/mobile UI
- Animated hero and hazard scenes

## Run
```bash
npm install
npm run dev
```

## Important
This is a learning/practice application, not an official DVSA test. Rules and legal details can change. Use the current GOV.UK Highway Code and DVSA materials for final revision.
